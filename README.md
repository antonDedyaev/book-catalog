# Каталог книг

## SPA-фронтенд по OpenAPI-спеке (тестовое задание)

Стек: Vue 3 (Composition API, `<script setup>`), Vue Router, Pinia, Axios, Vite, CSS.

Запуск:

Установка зависимостей
```sh
npm install
```

Запуск мока бэкенда из предоставленного в тестовом yml-файла через Prism *:
```sh
npx @stoplight/prism-cli mock book.yaml -p 4010 -d 
```    
Примечание: прокси /api/v1 → localhost:4010 настроен в vite.config.js через rewrite, поскольку Prism игнорирует servers.url из спеки;
Prism не валидирует multipart-запросы: в демо создание книги и редактирование со сменой обложки (POST/PUT) всегда получают 422, но сами запросы формируются корректно

Запуск в dev-режиме:
```sh
npm run dev
```        


## Объем работы
- каталог с поиском и пагинацией; 
- карточка книги; 
- CRUD для книги;
- список авторов;
- карточка автора;
- CRUD для автора; 
- логин (гость/юзер, кнопки и роуты закрыты по роли); 
- отчёт ТОП-10 авторов по году;
- подписка на автора *.

Примечание: в целях теста метода подписки добавил метод (POST /authors/{id}/subscribe, { phone }) и дописал в book.yaml для мока.
